# 食費のやりくり

月の予算から、食材・外食の支払いを引き算して「1日あたり」「今週あと」いくら使えるかを表示する、シンプルな食費管理Webアプリです。AIと一緒に作ったデモです。

## 機能
- 月ごとの予算を設定（毎月1日〜月末でリセット）
- 支払いを「食材」「外食」の2ジャンル＋合計金額だけで記録
- 残り金額、1日に使える額、今週（月〜日）あと使える額を表示
- 予算オーバーはマイナスの赤字で警告
- 月ごとにログを見返し、修正・削除が可能
- 食材と外食それぞれの合計・割合
- 予算が余った月の一覧と、その合計

## 使い方
`index.html` を開くだけで動きます。「デモデータを入れる」で、サンプルを確認できます。

データは閲覧しているブラウザの localStorage にだけ保存され、サーバーには送信されません。

## GitHub Pages で公開する
1. このフォルダをGitHubの公開リポジトリにpush
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
